PRIMARY BELL PLAYER — GITHUB PAGES SETUP

INITIAL PUBLISH (once):
1. Sign into github.com (a free account is enough).
2. Create a new PUBLIC repository named primary-bell-player.
3. Open the repository, choose Add file > Upload files.
4. Upload index.html, songs.js and .nojekyll from this package. Commit changes.
5. Open Settings > Pages. Under Build and deployment select Deploy from a branch.
6. Select main and /(root), then Save.
7. Your permanent site will be https://YOUR-USERNAME.github.io/primary-bell-player/
   It may take several minutes after publishing to become available.

USING ON AN IPAD:
Open that URL in Safari. Share > Add to Home Screen (optional).
Connect the HDMI adapter to the TV, then tap TV / Presentation Mode.

ADDING NEW SONGS:
- To publish for all devices: update songs.js on GitHub and commit it.
- You can send sheet music to ChatGPT and request an updated songs.js file.
- Your site address stays the same; the new library appears when Safari reloads.
- IMPORTANT: the in-app editor saves changes only in that browser; it does NOT publish them online.
- Previously edited songs stored in Safari override published versions on that device.
  Use a private Safari tab or clear this site's local data to check public defaults.

DISPLAY UPDATE: The big active melody row shows the current notes; two smaller upcoming rows are shown below. The next row moves up automatically after the current row finishes.

SATECHI R2 REMOTE:
- Connect iPad Settings > Bluetooth > R2 Remote. Switch remote to P (Presentation).
- Right/left arrows: next/previous melody note.
- Down/up arrows: jump to next/previous big melody row.
- Center button sends Enter, which may depend on focus; use on-screen Play/Pause if needed.
- Test on the actual iPad in Safari because remote keyboard events can depend on focus.
